# Support agents

Who answers the tally support inbox, and what each shift does.

| Shift | Hours (UTC) | Handles |
|---|---|---|
| Day | 08:00-16:00 | Bug reports, install problems, billing tickets |
| Evening | 16:00-00:00 | Bug reports, install problems |

## Instructions for every shift

- Ask for the output of `tally --version` before anything else.
- A report that the JSON output changed shape is urgent: tag it `contract`.
