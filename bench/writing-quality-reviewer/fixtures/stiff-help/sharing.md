# Sharing a board

Boardly provides board sharing functionality. Boards are shared via links. Links are generated from
the Share menu. Links grant view access by default. Edit access is configurable. Links expire. Access
is revoked when a link is deleted. A Boardly account is not required in order to utilize a view link.

## Create a link

1. Open the board.
2. Select **Share**, then **Create link**.
3. Choose **Can view** or **Can edit**.
4. Select **Copy link**.
