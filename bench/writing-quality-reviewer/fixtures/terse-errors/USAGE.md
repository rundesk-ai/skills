# Where each string appears

- `errors.folder_missing`: the error bar, when a synced folder's path no longer exists (it was moved,
  renamed or deleted). The person fixes it with "Choose folder…" on that folder's row in the sidebar,
  which is labelled exactly `Choose folder`.
- `errors.session_unsaved`: the error bar, when the local database failed to open. The current sync
  session still runs, but its history is lost when it stops or the person quits Tidepool.
- `errors.sync_paused_metered`: the status line, while sync waits for an unmetered network.
- `help.snapshots`: the help text under the Snapshots heading in Settings.

The content guide asks for errors that say what happened and what to do, in sentence case, with
contractions allowed.
