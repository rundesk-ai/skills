# Install Tidepool

In a few minutes you'll have Tidepool running and your first folder syncing. It's free for one
device, and it runs on macOS 14 or later and on Windows 11.

## Install on macOS

Download the DMG from the downloads page, open it, and drag Tidepool to your Applications folder.
The DMG is signed with a Developer ID and notarized by Apple, with its own notarization ticket, so
it opens even when you're offline.

The first time Tidepool starts, macOS asks whether it may read your Documents folder. Say yes if you
want to sync anything in there; you can change your mind later in System Settings, under Privacy &
Security.

## Install on Windows

Run the installer from the downloads page. It installs for your account only, so you won't need an
administrator password, and it adds Tidepool to the Start menu.
