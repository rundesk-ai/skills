# Release facts (from the build team)

- Free tier: one device. Supported: macOS 14+, Windows 11.
- macOS: DMG, Developer ID signed, notarized, ticket stapled, so Gatekeeper passes offline.
- macOS asks for Documents folder access on first launch; revocable in System Settings > Privacy & Security.
- Windows: per-user installer, no admin rights, adds a Start menu entry.
